# ultra-convenience-market-analysis
"Ритейл-форматы малого формата (Naletu, Заряд, Dixy Go и др.) в потребительских паттернах 2026"
## О проекте
Проект посвящён анализу магазинов формата ultra-convenience - таких как *Naletu*, *«Заряд»*, *Dixy Go* и др. - и их места в потребительских паттернах 2026 года. Задача - оценить восприятие данного формата российскими потребителями и выявить ключевые факторы, влияющие на выбор таких магазинов.
## Что было сделано
- Сбор данных с помощью скрапера 
- Предобработка и очистка собранного массива данных
- NLP-анализ отзывов и упоминаний для выявления отношения потребителей к формату
- Визуализация и обобщение результатов 
- Подготовка итоговой презентации и таблиц для заказчика
## Стек технологий
`Python` `Pandas` `NLTK` `NLP` `Веб-скрапинг` `Matplotlib` `Plotly` `Seaborn` `Excel`
## Файлы
- `01_selenium_review_scraper.ipynb` - веб-скрапер 
- `02_reviews_preprocess.ipynb` - предобработка отзывов
- `03_reviews_sent_analiz.ipynb` - сентимент анализ 
- `04_reviews_visualisation.ipynb` - финальный анализ и визуализация 
- `Ритейл-форматы малого формата в потребительских паттернах 2026.pptx` - итоговая презентация
- `reviews_final.xlsx` - таблицы с результатами
